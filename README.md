## 📖 Sobre o Projeto

Este projeto foi criado para demonstrar uma metodologia moderna de estudos utilizando Inteligência Artificial, com foco no **NotebookLM** como ferramenta principal de organização do conhecimento.

O objetivo é mostrar como transformar materiais de estudo em um **Caderno Temático Inteligente**, aplicando técnicas de aprendizagem ativa, engenharia de prompts, pensamento crítico e revisão espaçada.

Embora tenha sido desenvolvido inicialmente como parte de um desafio da DIO, o projeto foi planejado para ser uma referência aberta para qualquer estudante que deseja aprender utilizando IA de forma responsável.

# 🎯 Objetivos

Este projeto busca:

* organizar conteúdos de concursos de TI;
* transformar PDFs e materiais em conhecimento estruturado;
* ensinar como utilizar o NotebookLM para estudar;
* compartilhar prompts reutilizáveis;
* incentivar aprendizagem ativa;
* registrar erros, melhorias e experimentos com IA;
* criar um repositório colaborativo para estudantes.

# 🚀 Como utilizar

## Passo 1

Escolha um assunto.

Exemplo:

* Redes
* Banco de Dados
* Segurança
* Algoritmos
* Engenharia de Software

---

## Passo 2

Selecione entre três e cinco materiais confiáveis.

Exemplos:

* PDFs
* Apostilas
* Artigos
* Documentações oficiais

---

## Passo 3

Faça o upload no NotebookLM.

---

## Passo 4

Utilize os prompts disponíveis neste repositório.

---

## Passo 5

Gere:

* resumos;
* glossários;
* mapas mentais;
* perguntas;
* quizzes;
* flashcards.

---

## Passo 6

Revise utilizando repetição espaçada.
