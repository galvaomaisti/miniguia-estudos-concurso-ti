# 📚 Glossário Técnico

| API   | Interface de Programação de Aplicações | Consumo de serviços REST   | HTTP           |
| DNS   | Sistema de Nomes de Domínio            | Conversão de domínio em IP | Redes          |
| TCP   | Protocolo de Transporte                | Comunicação confiável      | Modelo TCP/IP  |
| SQL   | Linguagem de consulta                  | SELECT * FROM tabela       | Banco de Dados |
