# 📘 Miniguia de Estudos para Concurso de TI

Bem-vindo ao Miniguia de Estudos!

Este material reúne os principais resultados produzidos durante o desenvolvimento do projeto utilizando o Google NotebookLM como ferramenta de aprendizagem ativa.

O objetivo é fornecer uma estrutura simples, organizada e reutilizável para qualquer estudante de Tecnologia da Informação que deseja estudar de forma mais eficiente utilizando Inteligência Artificial.

## O que você encontrará

* Resumos estruturados.
* Glossário técnico.
* Mapas mentais em formato textual.
* Flashcards.
* Checklist de revisão.
* Plano de estudos.
* Estratégias de revisão.
* Recursos complementares.

## Como utilizar

1. Escolha um assunto.
2. Consulte o resumo.
3. Revise o glossário.
4. Faça os flashcards.
5. Responda às perguntas de revisão.
6. Atualize seu progresso.
7. Repita periodicamente utilizando revisão espaçada.

Este guia foi desenvolvido para ser atualizado continuamente conforme novos conteúdos forem estudados e novas experiências forem registradas.
