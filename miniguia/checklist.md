# ✅ Checklist de Revisão

Antes de considerar um assunto estudado, verifique se você consegue:

* [ ] Explicar o conceito com suas próprias palavras.
* [ ] Resolver questões sobre o tema.
* [ ] Identificar erros comuns.
* [ ] Relacionar o assunto com outros conteúdos.
* [ ] Citar exemplos práticos.
* [ ] Identificar aplicações no mercado.
* [ ] Resumir o tema em até cinco minutos.
* [ ] Ensinar o conteúdo para outra pessoa.

Se alguma resposta for negativa, retorne ao material e revise os pontos necessários.
