# 🧠 Mapas Mentais

Utilize mapas mentais em texto para visualizar as relações entre os conceitos.

Exemplo:

```
Redes de Computadores

├── Modelos

│   ├── OSI

│   └── TCP/IP

├── Protocolos

│   ├── TCP

│   ├── UDP

│   ├── HTTP

│   └── HTTPS

├── Equipamentos

│   ├── Switch

│   ├── Hub

│   ├── Roteador

│   └── Firewall

└── Segurança

    ├── VPN

    ├── SSL/TLS

    └── Criptografia
```

Monte um novo mapa mental para cada disciplina estudada.
