# 🚀 Aprendizagem Ativa

Neste projeto a IA não substitui o estudante.

Ela atua como uma ferramenta de apoio.

A aprendizagem ocorre quando o estudante:

- lê;
- pergunta;
- resume;
- explica;
- revisa;
- responde questões;
- aplica o conhecimento.

O NotebookLM foi utilizado para estimular essas atividades ao longo do processo de estudo.

A participação ativa do estudante é fundamental para a retenção do conteúdo.
