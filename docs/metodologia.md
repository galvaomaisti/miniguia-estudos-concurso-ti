# 📚 Metodologia de Estudos

Este projeto utiliza princípios modernos de aprendizagem.

## Aprendizagem Ativa

O estudante deixa de ser apenas um leitor e passa a construir o próprio conhecimento.

Foram utilizadas atividades como:

- elaboração de perguntas;
- criação de resumos;
- construção de glossários;
- produção de mapas mentais;
- revisão constante.

---

## Active Recall

Em vez de apenas reler o conteúdo, a IA foi utilizada para gerar perguntas que estimulam a recuperação das informações pela memória.

---

## Spaced Repetition

Os assuntos podem ser revisitados periodicamente utilizando os prompts de revisão disponíveis neste repositório.

---

## Técnica de Feynman

Após estudar um tema, ele é explicado em linguagem simples, como se fosse ensinado para outra pessoa.

---

## Pensamento Crítico

As respostas produzidas pela IA não são aceitas automaticamente.

Sempre são comparadas com as fontes utilizadas.

---

## Engenharia de Prompts

Diversas versões dos prompts foram testadas.

Os resultados foram registrados para identificar quais estratégias produziram respostas mais úteis.
