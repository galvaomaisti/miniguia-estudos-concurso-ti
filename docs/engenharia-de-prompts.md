# 🧠 Engenharia de Prompts

Durante o desenvolvimento do projeto foram realizados diversos experimentos para melhorar a qualidade das respostas.

## Exemplo 1

### Prompt

Explique Redes de Computadores.

### Resultado

Muito genérico.

---

## Exemplo 2

### Prompt

Explique Redes de Computadores utilizando exemplos do cotidiano.

### Resultado

Muito melhor.

---

## Exemplo 3

### Prompt

Explique Redes de Computadores como se eu fosse um candidato de concurso público.

### Resultado

Resposta mais detalhada.

---

## Lições Aprendidas

Quanto mais contexto é fornecido para a IA, melhores tendem a ser as respostas.

Prompts objetivos produzem resultados mais consistentes.

Solicitar exemplos facilita a compreensão.

Solicitar analogias melhora o aprendizado.

Solicitar comparações reduz ambiguidades.
