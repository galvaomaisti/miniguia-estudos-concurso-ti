# 🔍 Pensamento Crítico

Toda resposta produzida pela IA deve ser analisada criticamente.

Foram adotadas as seguintes práticas:

- comparar diferentes fontes;
- verificar conceitos técnicos;
- identificar possíveis inconsistências;
- revisar informações utilizando documentação oficial;
- registrar dúvidas durante o estudo.

A IA é utilizada como apoio ao aprendizado, não como única fonte de informação.
