# 💻 Como Utilizar o NotebookLM

## Passo 1

Escolha um assunto.

Exemplo:

- Redes
- Banco de Dados
- Linux
- Segurança

---

## Passo 2

Selecione materiais confiáveis.

Exemplos:

- PDFs
- Apostilas
- Documentações oficiais

---

## Passo 3

Faça o upload no NotebookLM.

---

## Passo 4

Utilize os prompts disponíveis neste repositório.

---

## Passo 5

Gere:

- resumos;
- glossários;
- flashcards;
- mapas mentais;
- perguntas;
- simulados.

---

## Passo 6

Revise periodicamente utilizando repetição espaçada.
