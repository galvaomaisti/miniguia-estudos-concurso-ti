# 📚 Curadoria de Fontes

Esta pasta reúne referências utilizadas durante o desenvolvimento do projeto.

Critérios de seleção:

* fontes oficiais;
* materiais gratuitos quando possível;
* livros reconhecidos;
* documentação técnica;
* artigos acadêmicos;
* conteúdos atualizados.

Sempre que possível, priorize a documentação oficial do fabricante ou da tecnologia estudada.
