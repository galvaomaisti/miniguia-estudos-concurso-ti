# 📄 PDFs

Antes de importar um PDF para o NotebookLM, verifique:

* autoria;
* data de publicação;
* atualização do conteúdo;
* confiabilidade da fonte;
* licença de uso.

Registre para cada PDF:

* título;
* autor;
* ano;
* assunto;
* origem;
* observações.

Essa organização facilita futuras revisões e aumenta a rastreabilidade das informações utilizadas no projeto.
