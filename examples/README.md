# 📂 Exemplos Práticos

Esta pasta reúne exemplos reais produzidos durante o desenvolvimento do projeto.

O objetivo é documentar o processo de aprendizagem utilizando o Google NotebookLM como ferramenta de apoio aos estudos.

Cada exemplo apresenta:

* objetivo;
* fontes utilizadas;
* prompt aplicado;
* resposta obtida;
* análise crítica;
* melhorias implementadas;
* principais aprendizados.

Esses registros demonstram como a qualidade dos resultados depende da combinação entre boas fontes, engenharia de prompts e validação crítica das respostas produzidas pela IA.
