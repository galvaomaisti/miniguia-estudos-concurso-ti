# Caso 03, Resumo Estruturado

## Objetivo

Produzir um resumo sobre Banco de Dados.

## Processo

1. Importação das fontes.
2. Solicitação de resumo.
3. Revisão manual.
4. Comparação com a documentação original.

## Resultado

O resumo final apresentou:

* conceitos principais;
* exemplos;
* aplicações práticas;
* observações relevantes para concursos.

## Aprendizado

Os melhores resultados surgiram quando o resumo foi solicitado em tópicos hierárquicos.
