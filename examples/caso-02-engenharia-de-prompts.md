# Caso 02, Engenharia de Prompts

## Prompt Inicial

Explique o protocolo TCP.

### Resultado

Resposta correta, porém superficial.

---

## Prompt Aprimorado

Explique o protocolo TCP como se eu estivesse estudando para um concurso público de TI.

Apresente:

* definição;
* funcionamento;
* exemplos;
* diferenças para UDP;
* principais questões cobradas em provas;
* pegadinhas mais comuns.

### Resultado

A resposta tornou-se mais organizada, detalhada e direcionada ao objetivo do estudo.

## Conclusão

Adicionar contexto e especificar o formato esperado aumenta significativamente a qualidade das respostas.
